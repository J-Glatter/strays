# Project map

```
Package.swift                 StraysCore (library) · Strays (app + CLI) · StraysCoreTests
Resources/Info.plist          LSUIElement menu bar app, bundle id com.glatter.strays
Resources/AppIcon.icns        generated by scripts/make-icon.swift
install.sh / uninstall.sh     per-user install, no sudo
scripts/build-app.sh          swift build → build/Strays.app, ad-hoc codesign (UNIVERSAL=1 for arm64+x86_64)
scripts/dist.sh               universal zip in dist/
Sources/StraysCore/           detection (see CLAUDE.md)
Sources/Strays/               main.swift · StraysApp.swift · Store.swift · CLI.swift · LoginItem.swift · Views/
Tests/StraysCoreTests/        CommandNamer, Classifier, parsing/formatting
```

Data flow: `Sampler.sample()` → `Snapshot` → `Classifier.classify()` → `Report`
(hidden, claudeSessions, sleepBlockers, machines) → `Store` (@MainActor) → SwiftUI panel and menu bar label.
`Engine` confines the sampler to one serial queue and is shared by the app and the CLI.
